# AI Value Loop
## From Tokens → Verified Outcomes → Business Value → Action

### Purpose
Create a common language for AI profitability that works across technical, business, and partner teams.

The method connects **Token-to-Value** measurement with **Value-to-Action** decision-making so teams can answer three simple questions:

1. **Are we getting useful work for the AI spend?**
2. **Is that work creating real business value?**
3. **What should we do with the next dollar?**

**Token-to-Value asks:** *What are we getting for the AI resources we consume?*

**Value-to-Action asks:** *Given the value and evidence, what should we do with the investment?*

## Common Language

| Step | Plain-English question | What it means |
|---|---|---|
| **FRAME** | What job are we funding? | Define the workload, baseline, and accepted work unit. |
| **MEASURE** | What did AI consume? | Tokens, models, tools, infrastructure, human effort, and cost. |
| **VERIFY** | Did it produce useful work? | Accepted Work, quality, failures, and cost per useful unit. |
| **OUTCOME** | Did anything change in the business? | Workflow and business outcomes beyond the AI system. |
| **VALUE** | Was the change worth more than it cost? | Attribution, economic value, and total relevant customer cost. |
| **TEST** | How much should we believe it — and what would break it? | Evidence confidence and value resilience. |
| **DECIDE** | What should we do now? | Scale / Sustain / Optimize / Prove / Restructure / Pause / Retire. |
| **ALLOCATE** | Is this the best use of the next dollar? | Compare incremental value and cost against competing opportunities. |
| **PROTECT** | What happens if we lose it? | Dependency and continuity investment. |
| **REASSESS** | What would make us change our mind? | Monitoring, triggers, and reallocation. |

## Five-Question Executive Version

```text
SPEND → WORK → VALUE → DECIDE → CAPITAL
  ↑                              │
  └──────── LEARN / REASSESS ────┘
```

- **SPEND** — What are we paying for?
- **WORK** — What useful work are we getting?
- **VALUE** — What business value is that work creating?
- **DECIDE** — What should we do about it?
- **CAPITAL** — Where should the next dollar go?

## Canonical Vocabulary

- **Useful Work** — AI output that passes the workload's acceptance criteria.
- **Cost per Useful Work** — Cost to create one accepted unit of work.
- **Business Outcome** — What changed outside the AI system.
- **Attributable Value** — Economic value credibly connected to the AI workload.
- **Total Customer Cost** — Relevant end-to-end cost of operating the workload, not just model cost.
- **Net Economic Value** — Attributable Value − Total Relevant Customer Cost.
- **Next-Dollar Economics** — Value and cost of the next proposed increment, not the historical workload.
- **Evidence Confidence** — How strongly the current claim is supported.
- **Value Resilience** — How much conditions can worsen before the economic case breaks.
- **Decision Deficit** — What currently prevents the workload from moving forward: evidence, execution, structure, economics, or control.
- **Portfolio Action** — Scale / Sustain / Optimize / Prove / Restructure / Pause / Retire.
- **Dependency Exposure** — Economic consequence if access to the capability is lost.
